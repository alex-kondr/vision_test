# ⚡ AutoFlow Assistant [Gemini Vision + Smart Vision Edition]
> **Розумний помічник для автоматизації пошти та документів з комп'ютерним зором (Gemini Vision + OpenCV), семантичним розпізнаванням елементів і контекстних меню при зміщеннях, розмежуванням кліків по області/елементу, прокруткою до низу та вибором файлів.**

---

## 🎯 Ключові можливості

1. **🧠 Семантичне розпізнавання елементів (Gemini Vision)**:
   - Розпізнає контекст елементів (наприклад, пункт контекстного меню **"Додаткові дії"** або кнопки дій), навіть якщо вікно чи меню **зміщено на 10-25%** на екрані.
   - Підтримує багаторазове навчання (банк шаблонів) для покращення якості розпізнавання з кожним сеансом.

2. **🔲 Розмежування типу кліків (Область vs Кнопка / Пункт меню)**:
   - **🔲 Клік по області**: використовується для фокусування списків, таблиць або контейнерів (не прив'язується до пікселів змінного вмісту).
   - **🔘 Клік по елементу / кнопці**: точний клік по конкретній кнопці із застосуванням візуального зразка та порогу збігу.
   - **📋 Пункт меню**: вибір пунктів контекстного меню із семантичним пошуком за назвою.

3. **📜 Обов'язковий початковий блок дій**:
   - Стандартний робочий процес починається з: **Клік по області списку ➔ Прокрутка списку до самого низу ➔ Вибір файлу**.
   - Додається в 1 клік кнопкою **`✨ Старт (Область ➔ До низу ➔ Файл)`** на панелі інструментів або кнопками плаваючої панелі запису.

4. **📁 Контекстне меню знайдених файлів**:
   - Розумний сканер екрана (Gemini Vision / евристика) виявляє файли та документи в списку.
   - Під час виконання з'являється зручне спливаюче контекстне меню з переліком усіх знайдених файлів, можливістю швидкого вибору останнього файла внизу або пропуску кроку.

5. **⏸ Точки схвалення (F8) та Пауза запису (F9)**:
   - Модальні вікна схвалення для контролю ключових кроків оператором (перевірка адреси, аркушів).
   - Пауза запису виключає запис зайвих ручних дій.

6. **🔁 Багаторазові цикли (наприклад, 50 листів)** та безпечна зупинка клавішею **Esc**.

---

## 🚀 Швидкий запуск

1. Запустіть файл **`start.bat`** або виконайте у консолі:
   ```bash
   python main.py
   ```
2. Введіть або збережіть ваш Gemini API ключ (опціонально для максимальної точності семантичного розпізнавання меню та файлів).

## 🎬 Керування під час запису (Плаваюча панель Toolbar):

| Кнопка / Клавіша | Призначення |
| :--- | :--- |
| **`🔘 Кнопка/Елемент`** | Записує клік по конкретній кнопці з візуальним шаблоном. |
| **`🔲 Клік по області`** | Перемикає режим: наступний клік записується як клік по області (фокус списку). |
| **`📜 До низу`** | Додає команду автоматичної прокрутки списку до самого низу (PageDown/End/Scroll). |
| **`📁 Файл (Меню)`** | Додає крок пошуку файлів на екрані та показу контекстного меню оператору. |
| **`⏸ Точка (F8)`** | Додає модальну точку схвалення оператора. |
| **`⏸ Пауза (F9)`** | Тимчасово ставить запис на паузу (ручні дії в цей час не записуються). |
| **`⏹ Стоп (F10)`** | Завершує запис і повертає список дій до головного вікна. |

## 🛠️ Гнучкий конструктор дій ("➕ Додати дію"):
Натисніть кнопку **`➕ Додати дію`** (або двічі клікніть по будь-якому рядку для редагування), щоб точно налаштувати дію за допомогою мишки:

- **🔲 Вибір області**: 
  - Натисніть **`🖱️ Виділити область мишкою`** — екран затемниться перехресним курсором.
  - Протягніть мишкою потрібну зону списку або панелі. Програма запам'ятає межі прямокутника та розрахує центр кліку для надійного фокусування.
- **🔘 Клік по елементу / пункті меню**:
  - Інтерактивне виділення кнопки або пункту меню мишкою на екрані.
  - Автоматичне розпізнавання тексту через OCR / Gemini Vision (наприклад, *"Додаткові дії"*).
  - Вибір кнопки миші: **Лівий клік**, **Правий клік (контекстне меню)**, **Подвійний клік**.
  - Чекбокс **Smart Vision** з динамічним пошуком навіть при зміщенні вікна на 10-25%.
- **📁 Вибір документу (Пошук по 2 областях з пріоритетом)**:
  - **Область 1** та **Область 2**: можливість протягнути дві незалежні області екрана, де можуть з'являтися назви файлів чи документів.
  - **Пріоритет пошуку**:
    1. *Область 1, якщо не знайдено — Область 2* (шукає спочатку в головній зоні).
    2. *Область 2, якщо не знайдено — Область 1* (зворотний пріоритет).
    3. *Об'єднати файли з обох областей* (збирає всі унікальні файли).
  - Опція відображення спливаючого **Контекстного меню** зі списком знайдених файлів для вибору оператором.
- **🛑 Очікування підтвердження користувача**:
  - Налаштування заголовка та детального тексту інструкції для оператора під час виконання.
- **📜 Прокрутка до низу**:
  - Автоматична прокрутка списку вниз для відображення нових документів.

## 📝 Покроковий приклад створення сценарію:

1. Натисніть **`✨ Старт (Область ➔ До низу ➔ Файл)`** або створіть власні кроки через кнопку **`➕ Додати дію`**.
2. Для кроку **Вибір документу** виділіть дві області на екрані та оберіть потрібний пріоритет.
3. Додайте кліки по елементах (наприклад, пункт **"Додаткові дії"**) — програма зафіксує знімок і семантичну назву елемента.
4. Додайте точки схвалення оператора за необхідності.
5. Запустіть автоматизацію кнопкою **`▶ Запустити автоматизацію`**.
