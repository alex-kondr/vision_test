# ⚡ AutoFlow Assistant [Smart Vision Edition]
> **Розумний помічник для автоматизації пошти та документів з комп'ютерним зором (Smart Vision), точками схвалення, паузою запису та циклами.**

---

## 🎯 Чому це зручно?
1. **⏸ Пауза запису (F9)**: якщо вам потрібно під час навчання програми перемкнутися на інше вікно, підглянути файл, скопіювати щось чи підготувати систему — ви вмикаєте паузу. **Жодні дії в цей час не записуються** і не потраплять у фінальний сценарій! Коли ви готові — натискаєте F9 знову, і час паузи не створить штучної довгої затримки.
2. **🎯 Smart Vision (комп'ютерний зір)**: розпізнає кнопки, виділені рядки документів та пункти контекстного меню, навіть якщо вони змістилися на екрані.
3. **🛑 Точки схвалення (F8)**: зупиняють виконання сценарію в потрібних місцях (перевірка адреси, заміна бланка в принтері) і чекають натискання Enter.
4. **🔁 Цикли (наприклад, 50 разів)**: автоматичне повторення для всієї черги листів.

---

## 🚀 Швидкий запуск
1. Запустіть файл **`start.bat`** подвійним кліком миші (або `python main.py` у консолі).
2. За замовчуванням увімкнено:
   - `[✓] 🎯 Smart Vision (пошук за зміщенням)`
   - `[✓] Чекати вибору листа на початку кожного циклу`

---

## 🎬 Кнопки керування під час запису (Плаваюча панель):

Коли ви натискаєте **`⏺ Навчити (Запис дій)`**, з'являється компактна плаваюча панель із кнопками та гарячими клавішами:

| Кнопка / Клавіша | Що робить |
| :--- | :--- |
| **`⏸ Точка схвалення (F8)`** | Додає модальне вікно очікування (наприклад: *«Перевірка адреси»* або *«Вставити бланк №1»*). |
| **`⏸ Пауза запису (F9)`** | **Призупиняє запис**. Усе, що ви робите в цей час (кліки, перемикання вікон), **НЕ записується**! Натисніть **F9** знову для відновлення. |
| **`⏹ Завершити (F10)`** | Завершує запис і повертає головне вікно зі списком усіх кроків. |

---

## 📝 Приклад процесу запису вашого сценарію:
1. Натискаєте **`⏺ Навчити (Запис дій)`**.
2. Вмикаєте **`F9 (Пауза)`** ➔ спокійно обираєте вхідний документ та адресата вручну ➔ вимикаєте **`F9`** (запис пішов).
3. Клікаєте по вкладці формування листа.
4. Натискаєте **`F8`** (створюється точка: *"Перевірка адреси"*).
5. Клікаєте *"Зберегти запис"*, чекаєте діалогу друку 1-го PDF, обираєте формат друку.
6. Натискаєте **`F8`** (створюється точка: *"Вставити 1-й аркуш у принтер"*).
7. Клікаєте *"Друк"*, формується 2-й PDF, обираєте формат друку.
8. Натискаєте **`F8`** (створюється точка: *"Вставити 2-й аркуш у принтер"*).
9. Клікаєте *"Друк"*.
10. Натискаєте **`F10`** (Завершити).

---

## ▶️ Запуск виконання
- Введіть кількість листів (наприклад, `50`).
- Натисніть **`▶ Запустити автоматизацію`**.
- Програма проведе вас по кожному листу, чекаючи вашого схвалення на кожному кроці!
- **Екстрена зупинка**: клавіша **`Esc`** у будь-який момент.
