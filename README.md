# ⚡ AutoFlow Assistant [3-Layer Hybrid Edition]
> **Гібридна система автоматизації Windows-програм та обробки документів. Замість ненадійного пошуку за фіксованими пікселями реалізовано 3-шарову архітектуру: Windows UI Automation (pywinauto/uiautomation) ➔ Клавіатурна навігація ➔ Комп'ютерний зір (локальний OCR + багатомасштабний контурний OpenCV + Gemini Vision).**

---

## 🎯 Гібридна архітектура з 3 шарів

Програма автоматично перевіряє шари по черзі — від найшвидшого і найнадійнішого до запасного:

### 🥇 Шар 1. Windows UI Automation (UIA)
- Бібліотеки **`pywinauto`** та **`uiautomation`** звертаються безпосередньо до дерева елементів операційної системи Windows.
- Знаходить кнопки, пункти меню, поля вводу та вкладки за назвою (`name`), типом (`control_type`) та `automation_id`.
- **Повна нечутливість до зміщення вікна**: навіть якщо вікно зміщено на 15–50% або розгорнуто на іншому моніторі, клік відбувається точно в центр елемента.
- Читає справжні елементи списків та таблиць (`ListItem`, `DataItem`) без екранних евристик.

### 🥈 Шар 2. Клавіатура
- Для друку та переміщення по меню: `Ctrl+P`, `Alt+літера`, `Tab`, `Enter`, `End`, стрілки навігації.
- Прокрутка списку до самого кінця виконується миттєво через клавішу `End` або ScrollPattern UIA замість повільних прокруток коліщатка.

### 🥉 Шар 3. Комп'ютерний зір (запасний варіант)
Якщо програма не підтримує UIA (Citrix, Java, нестандартний рендер):
1. **Швидкий локальний OCR (RapidOCR / Windows winocr)**: миттєво знаходить точний bounding box тексту (наприклад, *"Додаткові дії"* чи *"Зберегти"*) за 30–50 мс без виклику хмарних API.
2. **Багатомасштабний контурний OpenCV matchTemplate**: пошук на Canny-контурах (краях) у діапазоні масштабів **0.8–1.25**. Не ламається при виділенні рядка іншим кольором чи зміні системної теми/DPI.
3. **Gemini Vision API**: останній резервний шар для складних нестандартних візуальних елементів.

## 🖨️ Прямий друк документів (PDF)
- Підтримка швидкого друку без кліків у діалогових вікнах друку (через **SumatraPDF**, `win32api` або системний виклик друку).
- Економить 3–4 ручних кліки на кожному документі.

---

## 🛡️ Журнал виконання та скріншоти помилок
- Якщо на будь-якому кроці виникає збій, програма автоматично:
  - Зберігає повноекранний скріншот у папку **`logs/errors/error_YYYYMMDD_HHMMSS.png`**.
  - Фіксує номер циклу, номер кроку, тип дії та локатор елемента у **`logs/execution.log`**.
  - Захищає сценарій від випадкових змін під час виконання.

---

## 🚀 Швидкий запуск

1. Запустіть файл **`start.bat`** або виконайте у консолі:
   ```bash
   python main.py
   ```
2. Натисніть **`⏺ Навчити`** або додайте власні кроки.
3. Запустіть відтворення на потрібну кількість циклів (наприклад, 50 листів). Екстрена зупинка у будь-який момент — клавіша **Esc**.
